# Web / APP 体验规范 v0.1（草案）

2026-10-25 渠道更名：本文件“用户 APP”指 Telegram Mini App 客户交互，Bot 提供引导下单与消息；“司机 APP”指 iOS／Android 双平台目标。详见[渠道范围](telegram-and-driver-app-scope-v0.1.md)。当前仍是网页原型，不代表 Telegram 或安装包已接通。

本补充依据 V1.4 §6、design-standards.md、development-standards.md、system-boundaries.md、glossary.md。与 PRD 冲突以 PRD 为准；不修改 PRD、规则及验收编号。冻结后复核。适用运营 Web、调度 Web、仓库/财务 Web、司机 APP、用户 APP；目前 APP 指移动交互原型，不代表原生应用已交付。

## 1. 字体、颜色和布局

| 项目 | Web | APP |
|---|---|---|
| 页面标题 / 模块标题 | 24/18 px，600 | 22/18 px，600 |
| 正文 / 表单输入 | 14 px，400 | 16 px，400 |
| 辅助、标签、时间 | 最小 12 px | 最小 14 px |
| 关键金额 | 24 px，600，等宽数字 | 24 px，600，等宽数字 |
| 行高 | 1.6；不截断高棉文音标 | 1.6；系统放大后可换行 |
| 间距 | 4/8/12/16/24/32；页面 24、卡片 20 | 页面 16、卡片 16、控件间隔 8–12 |
| 触控区 | 主要操作最小 40 px | 最小 48 px，流程主操作 56 px |
| 圆角 | 控件 8、弹窗 12 | 同左 |

字体顺序 Inter / Noto Sans Khmer / Noto Sans SC / 系统无衬线。字体资源及授权随发布包核验，当前回退字体不冒充已内置字体。支持高棉语、英语、中文；三种语言采用同一信息层级，不用缩小字号解决溢出。金额、电话、编号保持 LTR；金额分开显示币种，保险费单列且不参与配送费分成。

正文 #0B2545，次要文字 #5B6B7F，背景 #F6F8FB，卡片白色，边线 #E3E8EF。成功 #0B7A5F、提醒 #9A5800、错误 #B42318、链接 #1D5FBF。品牌青绿 #13C29B 与橙 #F5A623 用于品牌和装饰，不作白底小字。状态必须同时有文字，不能只靠颜色。普通文字对比度至少 4.5:1。深色模式必须另验整套语义色，不直接反转图片；本轮原型只交付浅色。

## 2. 页面与菜单

日常工作在前、设置在后；一级页面最多一个主要流程按钮，详情页有返回并保留筛选。长页按队列/详情、基础资料/记录/财务分组；表格横向滚动留在容器内。Web 支持 1280–1920；移动端 360–460。大字体下允许纵向滚动，不固定内容高度。

运营：总览 → 外部接入 → 商品 → 仓库 → 车辆 → 司机 → 合作方 → 运费 → 提现 → 配送区域 → 权限。调度：地图工作台 → 订单 → 异常 → 快递委托 → 接入 → 合作方 → 区域。财务：核验 → 应付 → 提现 → 收款账户 → 运费。原型检查放最后。

用户 APP：寄件 / 订单 / 消息 / 我的。寄件复用外部订单复制、字段核对与配送费+保险费；订单只展示当前演示身份的订单。提交申请不代表车辆已接受。司机 APP 保留任务 / 订单 / 我的，任务操作条在菜单上方，右滑只打开确认，不直接改状态。

## 3. Toast、消息、声音和强通知

| 等级 | 展示和消失 | 声音 / 业务影响 |
|---|---|---|
| 成功、普通提示 | Toast 6 秒，可关闭；悬停/聚焦暂停计时 | 静音，不改状态 |
| 输入错误 | 字段旁及表单顶部，保留输入直到修正 | 不自动关闭表单 |
| 待办、临近时限 | 消息中心、页面状态卡，可标已读 | 默认静音 |
| 事故、持货退回、超时 | 持续强提醒、具体订单、责任人、处理入口 | 用户主动开启后，当前会话新紧急事项单次提示；不循环响铃 |

消息已读不等于业务已处理。业务解决由对应动作和证据决定；不得通过关闭 Toast、确认提醒或试听声音推进订单。声音可随时关闭，首次必须用户手势，浏览器限制时明确反馈。系统锁屏推送、后台推送、电话/SMS 升级告警未接入。通知内容按身份与操作范围过滤，不在用户端显示内部财务、其他客户或车辆事故明细。

强提醒不强制抢焦点、不阻断正在填写的表单；禁止自动跳转、倒计时自动确认。事故先提示安全停车和求助，业务操作不得鼓励驾驶中使用。

## 4. 弹窗与防误操作

弹窗必须有标题、对象编号、动作名称、当前状态和后果说明。确认按钮使用具体动词；返回/关闭不提交。打开时焦点落在标题，Esc 关闭须经过未保存输入保护，关闭后还原触发点。一次只有一个业务弹窗。提交中防重，失败保留字段并聚焦错误；服务端仍须检查权限、版本、幂等及状态，前端不能代替。

取消、退回、保管转移、签收、核验、提现审批分别提示影响。滑动到终点只进入核对界面；部分签收必须输入实际件数；截图/照片不等于银行到账；已送达不等于财务结清。危险操作不得设默认勾选，未经审核不得通过批量按钮跨过逐单证据。状态不可从下拉框任意改写。用户取消需根据取货前/后分别进入取消或退回，不能用删除掩盖货物责任。

## 5. 图片展示及本地预览

商品图用 1:1 缩略图，可裁切展示但原图不修改；交接、签收及凭证用 contain 保留完整边缘。缩略图 96 px，点开大图可放大与返回；无图显示占位和文字；加载失败给出重试，不显示“上传成功”。图片有用途说明和替代文字，证据不得只以颜色描述。

原型选图限制：JPEG/PNG/WebP，每张不超过 5 MiB，每批最多 6 张，解码后边长不超过 8192 px；扩展名不足以证明类型，需实际解码。拒绝 SVG、空文件及损坏图片。可逐张移除、重新选择、预览；选择过程中标注处理状态。当前仅本地预览，关闭弹窗后释放图片，不能替代必填凭证编号，也不计入已上传证据。

生产待实现：签名上传、服务端内容验证/限额、恶意文件检测、权限隔离、EXIF 定位隐私处理、失败重试与断点续传、提交前附件完成确认、证据留存及删除权限；网络成功前不得展示“已上传”。

## 6. 页面检查范围与验收

全量路由：access、areas、customer、dispatch、orders、exceptions、warehouse、finance、driver、prototype、partners、bookings、payables、integrations、operations、goods、inventory、vehicles、drivers、pricing、withdrawals。统一基础字号、语义颜色、按钮、菜单和对话框；状态分轴见 order-state-catalog.md。

复核：无小于 12 px 的 Web 正文；APP 辅助至少 14、正文 16；正常/空/失败/禁用/离线不误报成功；键盘可达；取消不变更状态；返回保留数据；图片失败可恢复；强提醒已读后业务仍待办。浏览器记录独立保存，不替代真机、屏幕阅读器、全语言、生产权限及推送验收。

## 7. 登录、启动、加载和 APP 弹窗（2026-10-24 补充）

统一入口 `prototype/entry.html`，支持 Web / 司机 APP / 用户 APP 三种布局。登录和启动由 `entry-ui.mjs` 维护，业务动作弹窗仍由原动作表单维护；消息弹窗共用 `showMessageDialog`。沿用现有 Logo、颜色、字体及间距，不增加 UI 框架。

| 场景 | 展示与行为 | 不得发生 |
|---|---|---|
| Web 登录 | 左侧品牌与仓配路线，右侧账号及口令；显隐、必填、忙碌防重、失败重试 | 输入真实密码被存入原型；把页面视为认证边界 |
| APP 登录 | 单列、48 px 操作区、16 px 输入；司机和用户身份分开 | 沿用上一次后台身份；混入其他用户订单 |
| APP 启动 | 使用原 Logo 轻微淡入位移；演示准备条；可跳过，约 1.1 秒 | 伪造真实数据进度；不可跳过的品牌广告 |
| 页面加载 | 骨架、状态文字和单一加载符号；保持容器稳定 | 显示空数据或 0 冒充加载结果 |
| 首页公告 | 本轮每次从 APP 演示登录进入后展示一次；知道了或 Esc 关闭 | 以关闭代表同意协议、授权设备权限或订单完成 |
| 强通知 | 红色语义边框 + 紧急文字 + 具体对象/原因；已看到与查看处理分开 | 已看到自动结案、派单、退款、签收；倒计时自动确认 |

当前登录使用固定演示口令 DEMO；Web 复用已有账号状态及范围投影，APP 固定演示身份。没有短信发送、注册、找回密码、令牌和服务器认证。帮助入口明确说明此边界。URL 与浏览器存储均可修改，因此该功能只用于设计评审，不能部署为真实登录。

正常登录演示等待约 450 ms，超时演示约 1.6 秒；这些都是可复现的评审参数，不是生产超时策略。网络失败/超时保留输入，解除忙碌后允许重试，不显示成功。演示口令不写入存储或 URL；成功后清空。

强通知入口来自消息中心的实际演示异常项；设计评审另有无业务对象的样式预览。原型不模拟后台自动推送或抢占正在编辑的表单。已有弹窗打开时不叠加第二个弹窗。强通知使用 alertdialog、其余用 dialog；打开聚焦标题，Esc/明确关闭按钮退出并还原触发点，处理按钮只导航至订单详情，由原有校验完成后续动作。

`prefers-reduced-motion` 开启时取消启动和骨架动画，启动等待缩至约 100 ms。动画不承载唯一信息，不循环播放声音。生产还需真实认证策略、会话过期/退出、多设备登录、推送权限、公告版本/频控与离线启动缓存；本轮不把未实现的后端能力表现为可用服务。
