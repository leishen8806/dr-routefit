## 2 V1.3 → V1.4 差异

V1.4 完整继承 V1.3 的正文、规则、案例、参数与工程附录（V1.4 §0）。差异的权威清单是 V1.4 [附录 G.4“与 V1.3 的冲突裁决”](../PRD-V1.4-review.md)，整合方案见 V1.4 第 21 章。摘要：

| V1.3 | V1.4 |
| --- | --- |
| 首期受控车队，默认不接社会司机 | 允许核验过的合作车；仍禁止开放司机市场 |
| 不做跨承运商 | 首期允许人工快递委托 |
| 首期只跑仓库到客户 | 增加三种执行方式；计划接力仍关闭 |
| 返程取货另议 | 纳入 R3-C，独立于退回 |
| 三维接入 R5 可选 | 配送摘要前移 R1-V，完整仓储与设备来源仍后置 |
| 只有应收与交款 | 增加合作司机与快递应付；不建资金平台 |
| 40 条规则／80 项案例 | 52 条规则／104 项案例；旧案例不删，新案例分阶段，初始 NOT_RUN |

M01–M09 的结论见需求会决策表，执行任务见[需求会后任务拆解](../tasks/post-meeting-task-breakdown-v0.1.md)。其中对首期范围的收窄：

- 数据库当前为 PostgreSQL 16，PostGIS 后置（M08，见 [ADR D24](ADR-D24-database.md)）。

## 5 冻结后的变更规则

- 修改 V1.4 正文、规则或验收案例，须提交 PR，由项目负责人批准，并在 [CHANGELOG](../../CHANGELOG.md) 记录原因与影响范围。
- 不改写已有 RULE/AT 编号；新增编号顺延。
- 实现与 PRD 冲突时以 PRD 为准；发现 PRD 有误，先改 PRD 再改实现。
