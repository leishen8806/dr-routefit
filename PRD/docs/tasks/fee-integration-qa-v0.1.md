# RF-QA-01 费用联调验收交接 v0.1

2026-10-25 · 技术自测与待执行的独立业务验收。任务编号用于协作，不新增或改变正式PRD／RULE／AT。费用页面仍为sessionStorage演示；本表不表示RF-WEB-01或RF-QA-01已通过。

## 1. 开始前核对

1. 按[基线交接](fee-baseline-handoff-v0.1.md)验证zip清单，在新目录恢复。记录snapshotId及文件哈希；Git HEAD单独记录，不能只用旧main复现未提交代码。
2. 按[服务README](../../../services/routefit/README.md)在自己的本机创建合成数据库、运行测试与服务。保留原有工作区，不复制他人的.local目录。
3. 费用联调地址为 `http://127.0.0.1:4180/prototype/`；4173仍是原演示。用本机 `npm run session:link` 建立企业A会话。企业B用 `npm run session:link -- 1`（新bootstrap提供）。
4. A、B用两个独立浏览器profile／隔离context；普通同浏览器标签页共用Cookie，不能据此模拟两个独立身份。A的两个普通标签页用于并发编辑测试。Cookie不隔离端口，其他127.0.0.1本机服务属于开发信任边界。
5. 检查GET `/dev/session` 的companyId、principalId、permissions和到期时间；不以页面角色下拉框判断服务端身份。来源身份过期按README本机续期并重启，不重建或删除已有库。

证据只记录对象ID、状态码、错误code、版本、金额、请求ID、请求次数和脱敏截图。不要保存激活ticket、Cookie、CSRF、数据库连接或完整HAR；前端只在内存保存CSRF。

## 2. 可复现的后端技术基线

在 `services/routefit` 执行：

```powershell
npm test
# 从自己的受保护环境注入本机一次性测试集群管理员连接
$env:ROUTEFIT_TEST_DATABASE_URL = $env:YOUR_LOCAL_POSTGRES_TEST_ADMIN_URL
npm run test:integration
# 已启动自己的开发库和API时再运行，产生新的合成草稿
npm run smoke
```

集成测试创建并清理自己随机命名的数据库／角色；不使用现有开发库作破坏测试。缺少测试连接应报告未执行，不能把仅单测通过算成真实数据库验证。
