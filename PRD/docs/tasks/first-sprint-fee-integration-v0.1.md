2026-10-25 · 配套[双人分工](../development-responsibilities-v0.1.md)。任务已编写并指定建议负责人，未通过聊天／GitHub向大旺发送，未获接单确认。任务ID仅用于协作，不替代PRD验收编号。后续用户已授权执行RF-COL-00与RF-API-01；本次本地交付见[交接说明](fee-baseline-handoff-v0.1.md)和[技术证据](../../../services/routefit/verification/rf-api-01/README.md)。大旺的设计与前端接线仍待领取。

## 1. 目标与现状

完成一个本地闭环：费用草稿列表 → 新建／选中草稿 → 分项保存 → 服务端试算 → 查询版本与快照。刷新页面后读到数据库结果；失败、断网或版本冲突时不假称保存成功。

现有[服务](../../../services/routefit/README.md)已经提供8个费用接口，见[接口说明](../../../contracts/pricing-api.md)、[HTTP模板](../../../contracts/examples/pricing.http)和[机器契约](../../../contracts/openapi.json)。[页面](../fee-settings-v0.1.md)仍使用sessionStorage。服务仅本地开发会话，无正式登录，无浏览器跨域授权；页面与API的实际端口按启动配置核对。

沿用现有Logo、[设计标准](../design-standards.md)与[Web／App体验规范](../web-app-experience-standard.md)。不重做整站、不改变正式计价规则、不接真实支付、不新增公开登录、不把草稿直接用于订单收费。

### RF-UX-01：产品、设计与验收先对齐

大旺在现有页面基础上完善草稿选择／新建、DR对客与承运采购分类、USD／KHR、19费目设置、试算明细、版本历史。标明数据库数据与原演示数据的来源；不把浏览器会话自动导成真实配置。

设计需覆盖加载、空白、未保存编辑、保存中、防重复点击、401会话失效、403无权限、404不可用、412版本冲突、422字段错误及断网。保留未保存输入；切换草稿或离开时避免静默丢失。保险与COD服务费、仓储及采购费用不得勾选配送分成。

交付：页面流程、字段与按钮规则、可运行页面或设计稿、验收清单，以及需要接口补充的具体问题。不能只交一张正常状态截图。

### RF-API-01：提供可用且隔离的本地联调路径

你负责选择并实现本机同源接入与开发会话建立方式，让页面能调用费用API。交付明确的页面地址、请求路径、Cookie／CSRF生命周期和启动／停止步骤；复用现有机制，避免无必要的第二套业务服务。客户端不得读取本地连接文件、把固定会话写进JS，或通过角色下拉框获得服务端权限；不使用通配CORS绕过源校验。

本任务是开发环境联调，不扩大为生产IdP交付。正式登录、完整客户权限及其发布门槛继续留在服务端规划。前端未具备本机会话接入时应显示明确不可用状态，不能回退到假保存。

同步实际接口变化与正反样例，修复阻塞接线的后端缺口；保持整数金额、企业隔离、版本、幂等和保险排除。提供两个合成企业的隔离测试办法，不共享凭据。

### RF-WEB-01：大旺完成前端真实接线

阅读费用接口后完成：

- 查询目录与本企业草稿，创建草稿，读取最新费目与版本；不以全局页面版本替代价表版本。
- 保存前从十进制输入精确转换金额／数量；USD美分、KHR整数、数量千分单位、比例基点。缺失不补零，不用浮点金额直接乘100修补。
- 保存携带If-Match和幂等键；只有服务端成功才显示数据库保存成功。网络未知结果重试沿用原键、原body及原版本；用户确认新的业务修改才换新键。
- 412时提示版本变化并保留输入，让用户比较／重新编辑，不盲目覆盖；错误按code及字段显示，不解析中文消息猜状态。
- 试算调用服务端，展示SIMULATION、币种、配置版本、费用行、合计、分成基数和保险独立金额；不把shareMinor显示为司机已得收入。
- 查询历史与持久试算，按nextAfter／nextAfterVersion处理列表。已保存快照不随本地编辑改变。
- 保留原演示场景入口并清楚标注；API失败不自动回退sessionStorage并继续声称保存成功。旧演示数据若要导入，应另列显式操作，不在本任务静默迁移。

修改以 `prototype/fee-settings-ui.mjs`、相关页面入口／样式／前端调用层及测试为主；调用层文件名由实施时确定。公共入口和服务文件先与RF-API-01划清修改人。中／英／高棉文沿用现有文案组织方式，新增中文fallback应列出待翻译项，不宣称已完成三语言验收。

### RF-QA-01：交叉验收

可直接执行的准备、技术证据与页面待验收项见[RF-QA-01验收交接表](fee-integration-qa-v0.1.md)。后端续轮补齐重复JSON字段／非法UTF-8防护；技术自测不替代大旺的独立业务走查。

| 场景 | 必须结果 |
|---|---|
| 新建草稿、保存、刷新／重新打开 | 从数据库读取同一草稿、金额和版本 |
| 两页面使用同版本编辑 | 一个成功，另一个412；不覆盖已成功修改 |
| 重复点击／同键重试 | 一次业务变化；能识别首次结果重放 |
| 保存请求断网／结果未知 | 不显示已保存；保留输入，按原键重试或重新查询核实 |
| 保险配置与试算 | 固定运费200美分＋货值10000美分×125基点=325；分成基数200、独立125；不是正式费率 |
| 未配置／停用／重复费目、非法金额 | 明确错误，不生成错误快照 |
| 会话失效／无权限／跨企业对象 | 401／403／404按契约处理，不展示他人数据 |
| 保存后改草稿 | 历史版本及已生成试算不被修改 |
| 原Demo场景 | 原测试和入口保持可用，来源标识不混淆 |

大旺提交浏览器走查、脱敏网络结果与操作步骤；你核对服务测试、真实数据库变更和权限／并发结果。复用现有测试，新增测试只覆盖新增接线与失败处理。验收记录包含实际基线SHA、环境、通过／失败／未运行项；RF-API-01已完成部分接口与浏览器技术验证；本表要求的具体页面按钮接线及交叉业务验收仍待RF-WEB-01后执行，不统一标为已通过。
