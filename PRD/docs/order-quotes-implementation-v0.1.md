# 订单报价实施切片

v0.1 草案，2026-10-25；与PRD冲突时以PRD为准，不改正文、RULE或AT。

在已完成的录单、受理及固定费策略审核之上，新增创建报价和读取报价两个操作；完整契约220操作，其中27本机实现、193仅设计。

链路：订单核验中 → 选择适用的已发布策略 → 服务端重新检查受理 → 确定性算价与持久快照 → 订单已生成报价 → 可重报或有原因退回。新报价递增订单版本，旧报价保留；有效性由当前订单、受理区域与到期时刻派生，不覆盖原金额。

005迁移新增pricing.order_quote（只追加、公司/客户RLS、源订单修订和策略发布外键）；订单投影新增quote_id。金额仍使用整数，保险独立并排除分成。没有生成应收、确认付款、承保或真实派单。

页面沿用原录单只读规范，仅新增quoted中文状态；完整报价页面由大旺依据[报价接口](../../contracts/order-quotes-api.md)接线，公共app.mjs/app.css和Logo图形不动。用户确定Slogan原文记录在[brand/SLOGAN.md](../../brand/SLOGAN.md)，作为品牌文案而非已兑现时效的证据。
