## 范围与证据

映射 76 项：R0-B 前置 7 项、R1 必测 40 项、R1 条件适用 11 项、R1-M 必测 13 项、R1-V 必测 5 项。余下 28 项属后续阶段，不是本次首期页面完成条件。

“UI + 服务端”指必须同时走查页面并验证领域状态、权限、幂等、并发或数据质量，不能仅凭按钮禁用通过。每次执行须记录输入、预期、实际、环境、候选 SHA、契约／策略版本和证据链接。当前没有执行证据，故统一 NOT_RUN。

条件案例未启用时仍记 NOT_RUN，原因写“本试点未启用”，不得记 PASS；未启用方式被服务端拒绝的要求仍须验证。R0-B 证据不替代 R1-V 实际接入；AT-15 在 R1-V 用实际候选重跑。AT-85 首期验证人工未知结果路径，未来 API 接入须补测。
