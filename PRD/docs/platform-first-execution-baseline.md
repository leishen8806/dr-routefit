# 平台跑通与基础计价派单执行基线

2026-10-25 完整计价设计见[快递配送与仓配计价体系](delivery-pricing-system-v0.1.md)。本文已确认付款、保险、分成及责任原则继续有效；补充方案不是正式费率批准，先完成基础计价和合理派单，不以研究扩大自动涨价或跨境业务。

2026-10-24，v0.1。用户最新优先级：先跑通平台，保证基础价格计算、合理派单和降本。不继续逐项追问保险与复杂售后细节。此优先级替代此前“先做部分签收与退款”的建议顺序；不改变安全约束及已确认业务原则。

## 当前主线

地图与导航成本按[专项方案](map-cost-optimization-v0.1.md)执行规划：优先业务筛选后计算候选道路时间、按事件重算、复用地图组件；司机先逐站打开外部地图导航。供应商、付费账户和具体配额仍待技术验证，不以公共免费服务或演示数据代替生产能力。

路线与调度专项设计见[配送路线规划与调度界面设计](route-planning-design-v0.1.md)，覆盖候选选择、接货空驶、站点时间表、逐段容量和同口径成本对比。

1. **统一订单与收费**：录入/导入 → 地址与货物核验 → 明确费用 → 客户确认 → 核验付款或有效月结资格 → 进入待派。展示页与工作台最终要使用同一订单，不继续扩充互不相通的场景。
2. **人工可控的合理派单**：先过滤资格、服务区域、可用窗口、已有任务、安全、载重、实际装载及所有承诺；再在可行车辆中比较接货成本、路线增量及承运费用。推荐须解释可行/排除原因，调度确认、司机接受后执行。
3. **交付与核账**：仓库放行 → 司机点收 → 配送签收 → 收款/交款核对 → 配送费分成与司机应付。预付订单不得在签收时再次收全款；获批月结单不冒充已到账。
4. **以可核对指标降本**：同一批订单比较独立配送与可行方案的总成本、里程、空驶、完成时间及异常成本；没有可靠成本来源时标未知，不给虚构节省百分比。

## 基础价格正确性

- 配送报价 = 基础费 + 明确的超距费 + 已启用且客户确认的独享/其他附加费 − 经批准优惠；总应收 = 配送报价 + 可选商业保险保费。平台基础货损保障包含在配送服务内，不单独收保障费。
- 固定币种、整数最小货币单位；公里转米后计算，明确实际超距或不足公里进位，再按报价规则取整；有效报价保存距离、计价规则、费用项和有效期快照。
- 分成只使用已确认的配送费口径，保费不参与。客户支付价格、司机应付和实际履约成本是三个不同数值，不能拿平台提成直接当利润，也不能通过强扣司机收入宣称降本。
- 必测：基础里程内/临界点/超出一点、距离精度、缺失费率、过期报价、地址改变、重复导入、非法负数、金额溢出、保费隔离及分成尾差。禁送区和最远服务距离不能用加价绕过。
- 初期费率可人工配置并版本化，不追求自动动态定价；演示费率不能直接成为正式运营费率。

## 本次已确认的业务原则

- 默认优先发货人付款；先付款并核验到账再派单，获批月结客户例外。不是禁止收货人作为明确约定的付款方。
- 司机取货后拒收，原配送费不自动退；发货人/收货人原因通常不退，平台/司机原因可人工审核退款。
- 客户方原因返仓由发货人承担，确认返仓报价；平台/司机原因先由平台承担，再内部核定，不自动扣司机收入。
- 发货人迟迟不确认时，调度安排安全暂存或返仓并留通知/处置证据；新增费用待确认/裁定，不直接形成已确认客户欠款。
- 客户退款不自动扣司机收入；已完成服务保留应付，核实司机责任并人工审核后才调整。
- 平台基础货损保障包含在配送服务中；商业保险可选加购、有实际保险机构承保，保费独立记账不分成。额度、除外责任、承保失败处置尚未确定，不推断用户已确认。

## 当前实现差距与收口顺序

新增[合作单位／个人结算规划](partner-settlement-and-funds-v0.1.md)：明确应付产生、对账、付款及资金沉淀展示。具体周结／月结周期待协议确认，不能把应付资金当利润；本轮优先保留准确应付和到期信息，不让复杂资金管理阻塞基础配送主线。

下一轮按[基础配送闭环实施任务](core-delivery-implementation-plan-v0.1.md)执行，先统一共享订单/报价，再补付款准入，避免继续复制独立展示模型；每卡有正常和拒绝分支通过条件。

现有源码已经有基础费/超距/闪送/保费计算、分成校验和人工派单约束；展示页车辆成本为固定合成数值，不能证明实际降本。既有展示主链仍是送达现金申报，不满足最新“先付款再派单”默认流程，必须先补付款前置和月结资格，不应宣称平台已完全跑通。

下一执行切片：统一报价与付款快照 → 付款/有效月结派单守卫 → 展示预付后交付不重复收费 → 合格车辆成本对比及人工选择 → 同单完成与对账。先完成普通自营配送；合作车/人工快递复用同一报价、订单和核账模型。无可靠道路时间时保留人工复核，不把固定矩阵冒充真实路线。

当前只做必要异常出口：拒单、过期、数量/金额差异、安全退回及人工裁定。部分退款、复杂保险、自动理赔、提现细节、完整 WMS 和复杂装箱不作为跑通基础主线的前置条件，继续保留在[后续闭环规划](future-closure-plan-v0.1.md)。

只有正常闭环、未付款阻断、月结资格失效阻断、报价失效阻断、重复请求不重复收费、保费不分成及不可行车辆不派发都通过，才称此切片跑通。真实定位、支付或成本接口未接通时明确说明，功能演示与生产启用分别验收。
