## 执行与证据

每条执行记录必须包含输入样例、预期输出、实际结果、执行环境、代码SHA、契约版本、策略版本、运行标识与必要证据。状态使用 PASS / FAIL / NOT_RUN；设计说明不是执行证据。

集合基数、外部服务、司机状态和已承诺路线等边界同时做负向与并发测试。统计指标不替代零越权、零重复写入等安全不变量。

任一新字段或规则改变后更新机器契约和样例；不能只改文档后声称端到端完成。
