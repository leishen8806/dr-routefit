## 后续闭环增补术语

来源：[后续闭环功能执行规划](future-closure-plan-v0.1.md)，不是新增 PRD 规则。代码写法为候选，待正式契约冻结。

| 中文 | 候选代码写法 | 定义 |
|---|---|---|
| 费用裁定 | FeeDecision | 对费用责任与金额的批准决定，不等于已收退款已执行 |
| 应收调整 | ChargeAdjustment | 引用原费用的追加增减记录，不改写原报价/收款 |
| 退款任务 | Refund | 向指定来源资金的付款方退还已核验款项的业务任务 |
| 付款尝试 | PaymentAttempt | 同一退款/提现任务的一次受控执行；未知结果不能另起无关联业务付款 |
| 资金预留 | BalanceHold | 为退款、争议或提现占用可用金额，防止并发重复使用；不是已付款 |
| 待检库存 | QuarantineStock | 已由仓库点收但尚未获准恢复可售的货物 |
| 接驳子任务 | IncidentTransferTask | 事故父单下的件级救援任务，不重复创建父单客户收费 |
| 来源订单关联 | ExternalOrderLink | 外部系统编号与内部订单的可追溯映射，包含修订版本 |
| 事务发件箱 | Outbox | 与业务变更同事务记录的待投递事件，不等于通知已送达 |
| 消费去重记录 | Inbox | 按事件标识记录消费结果，防止重放重复执行 |


## 跨端财务同步更新（2026-10-24）
