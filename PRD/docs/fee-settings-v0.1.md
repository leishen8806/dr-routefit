## 页面与业务边界

入口：运营中心 → 运费与分成 → 费用设置。相邻页签为费用试算、配置记录；原配送服务、订单分成、订单核对、入账明细继续保留。

| 分类 | 可独立设置的费目 |
|---|---|
| 基础运输 | 基础运费／首重、续重、超距、独享闪送 |
| 附加服务 | 上门取件、送货上门、偏远区域、搬运、上楼、等待、二次配送、拒收／退回运输、取消服务 |
| COD与保险 | COD服务费、配送保险费 |
| 仓储作业 | 仓储、入库、出库、包装 |

DR对客收费与VET／ZTO／CE／极兔采购费用分别维护；USD、KHR各自维护，不隐式换汇。品牌是费用草稿分类，不能证明该承运商已准入或接受该费率。[公开调研](research/2026-10-25-vet-zto-ce-jt-pricing.md)中的历史价与宣传价不预填为配置。

## 每项配置

- 独立费目、费用对象、币种、启用试算状态、适用线路／服务／包含范围、依据与变更原因。
- 固定金额：一次明确服务的每单金额。
- 按单位：单价、单位、包含量、计费步长；支持费目适用的kg、km、件、站、分钟、楼层、天、m³·日。超出包含量后向上取整到步长。
- 按比例：保险按申报货值，COD服务费按COD本金；0–100%，最多两位小数。该方式只适用于这两项，不用整单总额反算保费。
- 配送分成归属：DR运输及附加服务须明确勾选；保险、COD服务费、仓储费及采购费用锁定不参与。COD本金不是收费项目，不进入该费用设置表。
- 默认所有费目未配置、未启用。未知不能填0；0表示明确免费，也必须填写依据。停用保留历史，重新启用须保留有效配置。

USD金额最多两位小数，KHR金额为整数；计费数量、包含量、步长最多三位小数。费用逐行采用整数／十进制定点运算，比例费用HALF_UP到币种最小单位，再汇总。不接受负数、空金额、指数格式、非法单位、越界比例或溢出金额。

## 原型闭环

设置费用 → 保存本地演示版本 → 逐项选择本次服务与计费量 → 查看费用拆分及分成基数 → 保存试算快照 → 查看配置前后记录。

每次保存校验版本与幂等键；角色演示中运营可设置，财务只读和试算。账号预览使用原权限服务：全范围的运营资料维护权限可配置及试算；财务查看权限可查看及试算；限定仓库／车辆账号不能读取或修改全局价表。正式后台必须复现服务端鉴权，前端原型不是安全边界。

修改规则不覆盖历史试算；已有试算显示“配置已有变更，请重新试算”。所有原订单、应收应付、收款与司机分成仍使用其既有快照，试算不会发起收费、承保、派单或付款。

合成验证例：基础1 USD，超过3 kg后每0.5 kg收费0.25 USD，本次3.1 kg；保险按货值200 USD的1%；COD服务按本金200 USD的0.5%。结果：费用合计4.25 USD，保险2 USD，COD服务1 USD，配送分成基数1.25 USD。200 USD本金不计入该服务费合计。

本原型一个费用对象／币种／费目只保留一条当前规则及历史版本；线路范围为人工说明，不是可自动命中的区域合同。计费重量已由人工核定，尚未接入体积重转换、自动选价表、税费、优惠、封顶／最低费、商业审批、重复服务事件防重、正式报价落单及银行。跨币种不汇总；同一服务已包含于包价时，由试算人不重复勾选，不宣称已实现自动互斥校验。

正式接入须按[计价开发对照](pricing-development-map-v0.1.md)补完领域对象、契约及审批发布后，才能把配置用于订单报价；当前不存在新增可调用的生产HTTP接口，OpenAPI和SQL未修改。

验证证据：[本轮记录](../../prototype/records/2026-10-25-fee-settings/README.md)。这是组件及原型验证，不把完整PRICE-CASE、生产财务验收改为通过。
