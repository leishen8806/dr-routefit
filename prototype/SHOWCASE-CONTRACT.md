# 核心闭环演示契约 v0.1

2026-10-24。依据用户要求更新展示页、完成页面功能闭环。`showcase.html` 为隔离的合成场景，入口联到现有运营原型。不是 R2/R3 算法上线或正式 Gate 验收，不修改三张设计图任务。

闭环：录单（保留原单承诺）→ 三类候选车辆 → 重量/三轴尺寸/门洞/限定摆放格与逐段容量/时窗校验 → 查看方案 → 调度确认并复验版本 → 司机接受或拒绝 → 仓库放行 → 司机点收 → 运输 → 逐单现金申报与签收 → 财务核验及现金交款 → 只读中控/事件记录。

使用固定路线矩阵、轴向无旋转的限定摆放模式，绝不称为通用 3D 求解器或真实导航。每次调整货物重新计算，过期方案不能提交；拒绝回到候选并保留原单。货物实收不符阻断正常签收。B 全部拒收/联系不上已接入同单异常页；事故和部分签收仍使用原有独立业务原型。

展示页每个按钮必须产生可观察结果：预置反例、计算、选车、确认、拒单、交接核对、出发、申报/签收、财务核验、交款、查看中控、重置确认、返回现有工作台。保险独立账不参与配送分成。中控只消费同一隔离状态，不含业务写入口。

持久化使用独立 sessionStorage 键，不覆盖现有原型。保存失败明确告知；刷新恢复；只有显式确认重置才清除当前演示。金额整数分；输入边界、状态顺序、方案版本和重复点击由纯模型校验。视图提供调度/司机仓库/异常退回/财务/功能规划/中控/事件 TAB，避免长瀑布流。角色 TAB 为演示席位切换，不是真实鉴权。

同单异常分支：A 正常签收后，B 未交付、未收款、未投保 → 上报异常 → 调度复核恢复配送，或授权全部退回 → 司机返仓 → 仓库逐件点收至待检 → 财务记录批准后的全免调整 → A 收款/交款结清。减免不删除 B 原报价，不产生退款记录；此政策仅为明确标识的演示假设，不适用已付款或已投保业务。正常签收与退回在中控分别显示。来源与待建设清单见 `../PRD/docs/closed-loop-requirements-v0.1.md`。

本场景为 R3-A 同仓发车前合单：两单均在同一仓库交接，路线为仓库 → 原单 A → 新单 B → 返回。固定时间包含装载准备和行驶；不演示 R3-B 途中取货。原单的 60 kg 货物在各候选车前半货区已预置复核，新单仅使用后半独立货区；不能据此证明任意货型可装。
