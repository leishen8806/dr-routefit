# 调度地图与 TAB 工作台

v0.1 原型，2026-10-24。替代原调度首页的纵向堆叠布局，沿用现有 Logo 与设计标准；不修改 PRD、四份标准、规则或验收编号。

## 页面分区

- 地图调度（默认）：自营／合作车辆标记、车辆状态、司机、额定载重、任务装载、关联订单。桌面地图固定高度，右侧独立滚动；窄屏上下排列。
- 订单队列：原订单搜索、分页、筛选与动作。完整详情和事件默认折叠。
- 异常待办：仅呈现优先处理提醒，点击后切到订单队列并定位订单。完整异常列表仍保留原侧边菜单。
- 运营概览：订单／应收汇总和履约阶段分布；阶段按钮可跳转对应筛选。

TAB 使用 tablist/tab/tabpanel 语义，左右方向键、Home/End 可切换。地图支持缩放和显示全部车辆；车辆标记与下拉框均可操作。

## 地图调度闭环

点击车辆选中其有效任务，右侧显示车辆、司机与关联订单；选择已有派车订单时同步选中对应车辆。选择待派订单和空闲可用车辆，点击“向此车发送提案”，打开原派单确认框并预选车辆。合作车仍走原准入、费用及匹配确认；司机接受前不算派发完成。占用、容量或准入不满足时禁用提案动作并显示原因。

关联订单的撤回、承诺、取消、退回授权等动作复用现有状态守卫。调度不冒充司机接单或仓库点收。已有任务须先按原流程解除占用，不提供绕过规则的强制改派。快递承运方不伪装为车队车辆。

## 位置与数据边界

地图为固定合成位置样点与示意路网，不是 GPS、真实导航或 ETA。车辆状态取自会话订单，合作准入状态取自合作档案。任务装载按订单计算，含已交付部分时显式说明，不宣称实时称重、实时剩余容量或车辆遥测。
