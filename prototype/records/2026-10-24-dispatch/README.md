# 调度工作台：数据、异常与紧急信息

v0.1 原型，2026-10-24。沿用现有 UI、Logo 与设计标准，不修改 PRD 或四份标准。

- 新增 8 笔合成订单；基础场景从 3 单扩展至 11 单，覆盖待核验、待派、运输、持货退回、已送达及收款差异。
- 汇总展示当前订单、需跟进订单、紧急事项、合成订单应收和未核验应收。金额来自当前会话订单，不代表实际收入或到账。
- 优先处理区按紧急／关注／待确认分级，显示订单、原因、处理席和查看处理入口；每次页面渲染依据当前状态与承诺时间计算，不是推送监控。承诺临近的 30 分钟阈值仅作原型参数；时间已过不自动认定违约。
- 提醒包括原承诺已过、窗口临近、持货退回、收款金额差异、承运取消待确认、承运事件异常、待司机接单。首页最多展示 6 项，全部待办入口转入异常队列；事项数与去重订单数分开计数。
- 8 个履约阶段支持点击筛选；提醒直接定位对应订单与可执行动作。提醒随业务状态变化，不提供无依据的一键解除。
- 首次升级追加演示数据，不覆盖既有订单。已有车辆被占用时，新增场景降为待派，避免双占。补充按钮可重复点击且不重复造单。原型重置恢复 3 单，之后可手动补充繁忙场景。

验证：30 项模型测试通过；浏览器检查新增数据幂等、紧急卡、提醒定位、状态筛选、全部待办以及 1280/390px 无整页溢出；原 R1 完整流程回归通过。截图和结果 JSON 与源码快照同目录。浏览器脚本 browser-dispatch.js 可重跑。

限制：全为合成信息，无真实定位、ETA、告警推送或生产调度接入。没有新增业务阈值到 PRD；没有把原型测试作为正式验收通过。
