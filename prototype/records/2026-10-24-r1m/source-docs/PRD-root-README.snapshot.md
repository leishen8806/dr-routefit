# DR RouteFit

**Smart Dispatch & Delivery**
**DR 智能调度与顺路配送平台**

> The right vehicle. The right route. On time.
>
> 配对车辆，规划路线，准时送达。

DR RouteFit 面向即时货运与仓配配送，围绕车辆与货物装载匹配、及时送优先和顺路拼单形成业务闭环。地址、坐标、路网时间和车辆位置由地图基座 **Daen GeoCore** 提供。
