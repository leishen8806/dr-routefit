入口：`http://127.0.0.1:4173/prototype/showcase.html`。现有工作台顶部“闭环演示”和原型导航均已连接。设计契约见 `../../SHOWCASE-CONTRACT.md`。

## 已实现

- 五个工作席页签：调度计划、司机与仓库、财务核验、只读中控、操作记录。
- 同仓合单：录入新单尺寸/重量/数量/时窗/配送费/保险费 → 三车候选 → 选择并派单 → 司机接单或拒绝 → 仓库复核 → 司机点收 → 出发 → A、B 分别现金申报和签收 → 财务核验 → 司机交款 → 财务结清。
- 超载、尺寸、时窗无解反例；原单超时拒绝；方案版本复验；未重新评估的编辑阻止派单；错误件数/金额不推进；重复动作不能跨状态执行。
- 保险独立记账，演示配送提成 20%：配送 $44，保险 $2，应收现金 $46，平台 $8.80，司机应计 $35.20。没有真实付款。
- 独立 sessionStorage，刷新恢复；TAB 切换保留未评估输入；重置须确认；JSON 下载保留事件与签收、核验、交款凭证。
- 共享 `loadCheck` 修复内部宽/高遗漏与参数缺失放行问题，影响原有派车、地图候选、装载复核和事故接驳；正常场景保持不变。

## 边界

这是隔离的同仓发车前合单场景，不是途中动态取货。车辆前半区域的原单货物假定已人工复核；后半区域按固定方向格位校验，不构成通用 3D 装箱或任意货型承诺。ETA、成本及位置均为合成值，没有接入道路、GPS、银行、通知或正式身份系统。复杂事故、部分签收和退回仍在原有原型独立演示，A/B 数据不自动传入异常工作台。未完成生产集成或正式 Gate 验收；没有提交或推送 GitHub。
