# 仓配一体平台交互原型交付记录

日期：2026-10-24。范围：本地原型扩展，不是生产系统、银行支付或 PRD 验收。

## 产品选择与实现

一个仓配平台、运营与调度两个工作区，共用主数据与订单。用户确认：司机可申请提现，财务人工审核；按订单配置平台比例分成。测试 20% 仅为合成示例，不是正式默认值。详细契约见 ../../WAREHOUSE-PLATFORM-CONTRACT.md。

运营已包含商品规格、仓库资料、入库/库存/流水/退货质检、车辆容量/门洞/状态/司机绑定、身份资格、收款资料审核、分成与提现。调度继续地图为主，载重、容积、门洞与任务状态可查看。后台队列/详情及履约/资金/事件/快递/应急分标签；合作档案和应付拆列表与操作，历史折叠。

商品关联订单在承诺时预留，交接时出库，取消释放，退回待检、质检后放行。事故转运不重复出库。独享闪送单独录入附加费，确认客户费用、独享资源和人工时限，不转人工快递。

完整交付并核验客户款/司机现金后才分成入账；代收与收入分开，合作和事故费用独立处理。司机“我的”分身份/收入/提现/银行卡。提现冻结余额，审核后人工付款或驳回释放，在途禁换卡，申请保存账户快照。只保存合成身份凭证和账户后四位。
