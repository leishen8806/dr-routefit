# 登录、启动和通知弹窗验证记录

日期：2026-10-24。沿用既有 Logo、Web/APP 规范，未改 PRD 正文、规则或验收编号。

## 交付

- `entry.html?kind=web`：后台登录，复用已有本地账号状态和权限范围。
- `entry.html?kind=driver` / `entry.html?kind=customer`：两种 APP 登录，可跳过的启动动画，登录后的首页公告。
- 登录输入校验、口令显隐、重复提交锁定、失败/超时与重试；评审区提供可复现的场景。
- 全端共用骨架加载；尊重减少动态效果设置。
- 消息中心紧急事项可打开强通知弹窗：已看到不变更业务，查看处理进入对应订单。
- 修正司机端消息入口只绑定隐藏 Web 顶栏的问题。
