# 司机订单列表与问题处理

v0.1 原型增补，2026-10-24。依据用户要求与既有司机授权、履约、离线及事故规则，保持 PRD 正文和四份标准不变。原“同步与消息”底部入口改为“订单列表”，离线证据在顶部“待同步 · 查看记录”入口单独处理。

## 四个 TAB

| 分类 | 判定 | 操作与提示 |
| --- | --- | --- |
| 已超时 | 尚未结束且当前时间超过原服务承诺；采用金边时区 | 仍可接单/交接/配送/退回/上报；不自动取消、罚款、计费或重置承诺 |
| 配送中 | 其余未完成任务，包括待接、待装载、待取货、在途、事故接驳和退回 | 子状态原样展示；不能把待接单写成已取货 |
| 已完成 | 全部签收，或余货返仓后仓库点收结案 | 明确“退回已点收 · 非全部送达”；客户收款和交款未结清时继续显示账务待处理，并可打开任务处理 |
| 已取消 | 该司机本次任务因拒单、撤回、交接前取消、接单提案过期、接驳拒绝/撤回而结束 | 只读快照保留原货物、地址、结束时间和原因；不等同于客户订单全部取消 |

四类互斥，默认配送中，TAB 显示数量。列表按 8 条分页，支持订单号/货物/地址搜索及清空。切换分类重置页码。超时计算仅基于已知承诺，无时间则保持未知，不杜撰 ETA；列表每 30 秒重算，输入搜索或打开表单时不打断操作。

新产生的派单保存司机归属快照，已完成任务不随车辆更换司机而归给新人。被拒、撤回、过期的司机任务从本轮起保留历史；旧会话中未保存的历史不猜测补造。取消历史无业务动作，重新分配的客户订单不向原司机泄露后续内容。合作司机退出撤权后不再展示已撤销权限的历史。

## 司机常见问题与落地处理

| 问题 | 本轮处理 |
| --- | --- |
| 订单消失、不知道是否撤单 | 取消历史保留具体原因，明确本次任务与客户订单不同 |
| 承诺时间已过，不知道是否还能送 | 独立超时队列、原承诺时间和警示，仍按实际状态操作 |
| 部分签收仍持货，却显示完成 | 保留未完成状态，授权退回、到仓、仓库点收后才归档 |
| 没网，签收上传失败 | 顶部保留同步入口；订单卡标记“证据待同步 · 尚未生效”；重试不自动当作完成 |
| 找不到入口、收货人联系不上、拒收 | 上报问题→调度异常队列→记录处理结果→司机查看回复 |
| 车辆故障/事故、货损/少货 | 司机上报进入紧急待办；调度再单独执行事故冻结/转运或退回，回复不替代实物交接 |
| 堵车/预计延误 | 记录现场情况与调度安排；不改原承诺，不伪造位置/ETA |
| 收款差异、完成后还要交款 | 可上报收款问题，完成卡片显示账务待处理，财务流程仍独立 |
| 重复点击上报 | 幂等键防重；同单同类未处理问题不重复创建，处理后可再次上报 |
| 跨司机误看误操作 | 当前任务、取消历史和问题写入均校验司机身份；调度才能记录处理结果 |

问题上报在安全停车后操作。离线/数据过期时禁用上报与调度处理，只保留原有收款/签收离线证据能力；这里不是即时通讯或紧急呼叫服务。问题上报不自动变更货物保管、收款、订单状态或费用。调度回复也不自动更改地址、报价、授权退回或事故结案。
