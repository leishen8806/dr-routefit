# 后台账号、角色、权限与操作范围 · v0.1 原型契约

2026-10-24。沿用现有运营后台、Logo及设计规范；补充用户新增需求，不修改PRD正文、规则与验收编号，四份标准仍为v0.1草案。

## 管理入口

运营中心 → **账号与权限**（`#access`），分四个页签：

| 页面 | 能力 |
| --- | --- |
| 后台账号 | 创建账号标识/显示姓名，编辑多角色、启用/停用、操作范围，撤销全部模拟会话，模拟登录 |
| 角色管理 | 预置角色与自定义角色、业务工作席、功能权限勾选、使用账号数量 |
| 权限目录 | 订单、派单、异常、仓库、财务核验、付款、主资料、合作方、区域和导入的稳定权限标识 |
| 授权与操作记录 | 账号/角色变更前后快照、操作者、时间、对象，以及账号预览中的成功业务操作 |

预置系统管理员、运营管理员、调度员、仓库作业员、财务核验员、订单只读角色。系统管理员角色不可编辑；不得停用或降级最后一个启用的全范围管理员。账号标识唯一，停用代替删除，避免抹掉历史归属。

## 权限计算

账号多角色的功能权限取并集，但不会扩大账号操作范围，也不能绕过业务工作席职责、状态机、车辆容量、配送区域、保险与财务校验。

菜单根据角色功能及范围显示；操作按钮按同一权限配置禁用；最终业务写入在 `executeAsAccount` 再验证身份、会话版本、工作席、动作权限和对象范围，然后调用原有业务模型。普通账号的新动作未映射权限时默认拒绝。页面读取使用 `projectAccount`，而写入始终使用完整源数据，防止保存一个受限列表时误删其他仓库的订单。

财务查看、收款核验及付款授权独立。只读角色可见订单但不能派单。业务工作席是约束而非权限捷径：给运营席勾选财务权限不等于它可绕过原财务流程；需要分配适当工作席角色。区域发布、全局资料及其他未建立局部范围模型的功能，不向受限账号开放。

## 操作范围

当前仅一个演示企业，范围可选“本演示企业全部数据”或“指定仓库与自营车辆”。

- 指定范围至少选择一个有效仓库。
- 仓库与车辆条件同时满足：订单属于授权仓库，已绑定车辆还须在允许列表。
- 未派车订单按仓库可见；派车时单独校验目标车辆，不能通过伪造车辆ID越权。
- 车辆可选全部或指定清单；清单为空表示不允许派车，不代表全部车辆。
- 历史演示订单缺少仓库字段时按既有单仓基线WH01处理；正式迁移必须显式补齐归属，不能把这种兼容默认当作生产授权策略。
- 仓库库存按授权仓库过滤；车辆范围约束订单与派车，不对仓库总库存按车辆拆分。
- 范围外订单不进入列表、计数和地图订单视图；直接操作范围外ID会被拒绝。财务敏感凭证和司机银行资料按读取权限裁剪。
- 区域管理中的“可送/禁送”是服务准入规则，不是后台人员的访问范围。本期未增加配送多边形、部门、客户、订单创建人、外部合作车辆作为账号授权维度。

## 会话与变更

模拟会话绑定账号及授权版本；账号停用、修改角色/范围或撤销会话会递增版本，旧会话在下一次读取/操作时失效。角色修改会撤销所有引用该角色的旧模拟会话。保存使用对象版本和幂等键，避免陈旧表单覆盖及重复提交。

模拟登录会进入同一业务原型：只显示授权工作席、菜单和数据，退出预览返回演示管理员。账号预览不提供司机、用户端或原型重置入口；司机/用户原有演示流程继续独立测试。未保存账号/角色表单在切换管理页签前需保存或放弃，关闭/刷新有离开提醒。

## 安全与交付边界

**这是本地账号权限交互原型，不是真实认证或安全边界。** 顶部角色切换、模拟登录及退出返回管理员都是演示工具。浏览器本身持有完整合成数据，开发者工具可读写；不能据此前端裁剪声称实现了服务器数据隔离。

未创建密码、验证码、真实会话Cookie、SSO、MFA、邀请邮件或账号恢复流程。没有发送通知；不收集真实身份或付款凭据。未接入4174独立联调服务的认证，也未添加生产IAM接口或数据库迁移。

上线前需在服务端实现统一认证、企业隔离、每次请求授权、数据库范围限制、安全会话生命周期、身份恢复与不可篡改审计。当前审计只记录管理变更和账号预览下成功业务操作，未实现拒绝请求日志、IP/设备记录、不可篡改留存或审计导出。角色高风险组合、双人复核和跨企业管理仍需专项需求确认，不能认为本原型已经覆盖。

范围受限账号对合作委托、事故多车分配、全局资料等暂不支持的局部授权采取拒绝策略，不能通过给角色增加权限绕过；如需开放，先补充相关对象及关联记录的范围模型。
