# 订单录入页面与真实接口契约

v0.1 草案 · 2026-10-25。依据现有设计标准、P01和订单API；不改变正式PRD／RULE／AT。

## 入口与数据

`http://127.0.0.1:4180/prototype/orders.html`。先按服务README启动并以一次性链接建立本机开发会话，再访问此页。4173和GitHub Pages不提供该页面依赖的API；没有会话时只展示连接说明，不能保存。

本页独立于大旺负责的共享工作台。唯一业务数据源为现有5个客户／订单接口，保存落入PostgreSQL；不使用sessionStorage、localStorage或第二套订单模型。只读入获授权客户和草稿。页面与服务端都不把草稿等同于报价确认、收款或派单。

## 用户流程与失败出口

| 动作 | 成功结果 | 失败与恢复 |
|---|---|---|
| 连接／重连 | 显示当前企业、主体，加载客户和分页订单 | 401保持当前输入，另一标签页激活同一身份后重连；不在前端输入凭据 |
| 新建／编辑 | 取送信息、货物、服务与时间分3页签 | 字段错误关联说明并聚焦；跨字段校验仍由API负责 |
| 保存 | 等服务端确认后返回列表、显示版本；刷新从DB读取 | 不提前显示成功；重复点击被禁用 |
| 结果未知 | 保留原方法、URL、请求体、版本与幂等键 | 锁定输入，只重试原请求；不能换键新建 |
| 版本冲突 | 保留自己的输入，显示最新版本和完整草稿 | 不自动合并／覆盖；明确确认放弃后加载最新版本，再重新编辑保存 |
| 返回／新建／去演示台 | 无修改直接离开 | 未保存修改用现有样式的确认对话框；Escape继续编辑，默认焦点在继续编辑 |
| 切换开发身份 | 清空前身份表单、详情和列表，重新加载 | 不将原身份的待重试请求移交给新身份 |
| 列表网络失败 | 明确显示读取失败 | 不显示空列表成功；恢复后刷新 |

待重试请求只存在内存。刷新／关闭时使用浏览器beforeunload数据丢失提示；若仍关闭，重进后先核查订单，不自动重新提交。它不是跨设备持久事务队列。会话内身份变化主动重连才清除页面；服务端每次写入校验Cookie、CSRF和RLS。

## 录入语义

- 地址、联系人、电话、货物和时间来自实际输入；“填入合成样例”必须显式点击，取自机器契约样例，客户ID替换为当前授权客户。
- 单件包装尺寸cm、重量kg；未知填写null和原因，不用0代表未知。多行货物可增删，保留clientItemId；数量与限制继续受API校验。
- 所有时间明确为金边UTC+07；不随操作系统时区改变。编辑未改变时间时保留原始秒数精度。地址／地标变化清除旧坐标，待后续地址服务重新核验。
- 当前只支持PREPAID草稿和S1/S2/S3。录单页不操作报价、COD、月结授信、商品和凭证引用；不静默伪造这些能力。
- 客户列表每次100项、按游标加载更多；订单每页10项。游标和未保存内容仅保留本页会话，出于隐私不写URL／浏览器持久存储。不存在总数就只显示本页数量。

## 设计与组件映射

沿用`DESIGN.md`与`app.css`的运行时token：rf-navy／rf-teal／rf-bg／rf-line／rf-slate／rf-warning；Logo直接引用brand/logo白色横版。未新增色板、字体包或动画依赖。

共享`ui-primitives.mjs`的formField、escapeHtml、showToast；select和datetime-local沿用现有native所有权，弹出层随浏览器语言，页面明确时间语义。页签为普通导航按钮组，aria-pressed表达选择，键盘Tab及Enter可用。输入16px，目标至少44px；窄屏表单单列、表格局部滚动，表单不继承表格高度。

所有静态按钮在HTML默认禁用，模块绑定真实行为后才启用，脚本失败不会留下可点但无效的操作。未创建删除、批准、收款或派车按钮。

验证入口：`browser-order-entry.js`（临时注入激活链接，不保存票据）、`order-client.test.mjs`及`services/routefit/verification/order-entry-ui/`。中文评审页面，不宣称高棉语／英语和移动原生端已完成。

## 受理状态增量

服务端返回 validating 时显示“核验中”，只能查看，禁用字段、合成样例与保存；三个详情页签及返回仍可用。修改须通过受理接口有原因退回草稿，再刷新读取。接口规则见 [order-intake-api](../contracts/order-intake-api.md)。页面未增加区域发布或受理提交按钮。

## 报价状态

quoted显示已生成报价，只读查看，不能从页面直接编辑。当前没有报价表单/详情页；订单状态不代表报价仍有效，调用GET quote查有效性。返回草稿清除当前报价引用。沿用原字体/颜色/按钮及中文评审范围。

## 收款状态投影

订单列表不再写死未收款：unpaid未收款，reported收款资料待核销，partial部分核销，allocated已核销，未知值显示待核实。收款不推进履约，仍未派单。字段源于服务端资金记录；详情保持只读。没有新增财务表单，具体接线见 [预付契约](../contracts/prepayment-api.md)。已确认报价不可直接退回，须后续受控变更。
