# 司机任务页底部右滑操作 · v0.1

2026-10-24。沿用现有司机端、品牌与业务状态机；不改 PRD、规则或验收编号。

## 布局与动作

任务页的操作区固定在“任务 / 订单列表 / 我的”菜单上方，显示当前订单编号、辅助操作与下一步滑块。任务正文保留货物、联系人、承诺、保管、费用及收款状态；不再在那里重复放置主操作按钮。

主动作复用既有 actionItems，不新增第二套业务权限：

| 当前状态 | 右滑进入 |
| --- | --- |
| 待司机接受 | 接受任务确认 |
| 等待仓库放行 | 等待提示，不显示可执行滑块 |
| 仓库已准备交接 | 点收与取货表单 |
| 已取货 | 出发确认 |
| 配送中且需要申报收款 | 收款申报表单 |
| 满足放货条件 | 签收表单 |
| 转账已申报、未财务核验 | 签收滑块禁用，提示等待核验 |
| 已授权返仓 | 返仓到达确认 |
| 现金核验后待交款 | 交款凭证表单 |

合作司机与事故接驳沿用原动作和校验。拒单、其他可用动作、上报问题留在同一底部操作区，不能把滑动方向当作拒单或取消。订单列表与“我的”只保留菜单，不显示任务滑块。

## 交互规则

- 从左侧滑块把手向右拖动，松手时达到可移动距离90%才打开下一步确认/证据表单；单击、反向或不足距离的滑动不触发。
- 垂直手势优先允许滚动；pointercancel、失去捕获和重新渲染时复位。当前订单、版本、司机身份、角色、页签或模式变化后，旧手势不能继续触发。
- 右滑只进入既有确认流程，不自动签收、扣款、核账或省略交接凭证。取消表单后可重新滑动；原业务状态与版本校验继续生效。
- 把手可用键盘回车激活；另提供“无法滑动？点此打开同一步骤”按钮，辅助技术或行动不便用户不必强制拖动。
- 离线/过期状态继承原禁用规则；离线收款与签收仍是本机证据待同步，不假装服务端状态已推进。
- 底部操作区与菜单作为整体固定，宽度跟随司机应用容器；内容底部预留实际高度及安全区，提示消息显示在操作区上方，避免遮挡菜单。支持减少动态效果偏好。
