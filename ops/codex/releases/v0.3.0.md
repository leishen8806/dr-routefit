## 已知限制

1. **报价只含固定费。** 策略只能发布固定基础费、独享费和保险费；报价不含超距费，报价接口拒收距离依据（`CAPABILITY_DISABLED`）。这与[实施计划](../../PRD/docs/core-delivery-implementation-plan-v0.1.md) P01“报价包含超距计费米数／单价／取整”不一致。§4 固定场景中的超距费 $5 不能由服务端算出；10km 以内、10km 整、10.001km、最远服务边界、向上取整等距离边界未验证。后续见 [RF-PM-032](../tasks/RF-PM-032-distance-pricing-and-change-requote.md)。
2. **改单重核价只支持改地址、改时间。** 已确认报价后，仓库、货物、服务类型变更没有重核价路径。后续见 RF-PM-032。
3. **不含付款准入。** 预付收款申报与核验、核销、月结资格与派单守卫属 v0.4.0（P02）。候选报价的价差只作为同意证据，不生成补款应收或退款。
4. **已解除：费率策略按 ID 读取。** 报价页现按订单服务等级从已发布策略列表读取（支持分页与短 ID 展示），列表读取失败时仍可手填策略 ID。
5. **仅本机开发环境与合成数据。** 生产身份、真实地图与地理编码、KESS 与真实支付均未接入。
