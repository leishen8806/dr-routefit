## 已知限制

1. **报价只含固定费。** 策略只能发布固定基础费、独享费和保险费；报价不含超距费，报价接口拒收距离依据（`CAPABILITY_DISABLED`）。这与[实施计划](../../PRD/docs/core-delivery-implementation-plan-v0.1.md) P01“报价包含超距计费米数／单价／取整”不一致。§4 固定场景中的超距费 $5 不能由服务端算出；10km 以内、10km 整、10.001km、最远服务边界、向上取整等距离边界未验证。后续见 [RF-PM-032](../tasks/RF-PM-032-distance-pricing-and-change-requote.md)。试运营只接固定费范围内的订单。
2. **改单重核价只支持改地址、改时间。** 已确认报价后，仓库、货物、服务类型变更没有重核价路径。后续见 RF-PM-032。
3. **不含付款准入。** 预付收款申报与核验、核销、月结资格与派单守卫属 v0.4.0（P02）。候选报价的价差只作为同意证据，不生成补款应收或退款。试运营期间，收款、派单、配送按 [人工操作手册](../../trial/manual-ops-guide.md) 处理。
4. **已解除：费率策略按 ID 读取。** 报价页现按订单的服务等级从已发布策略列表读取（支持分页和短 ID 显示），列表读取失败时仍可手填策略 ID。
5. **身份是开发会话，不是正式登录。** 系统只监听本机。试运营部署在只允许 SSH 访问的 VPS 上，员工通过受限 SSH 隧道访问（见 [P01 受控试运营方案](../../trial/p01-controlled-trial-plan.md)），能否使用系统取决于员工密钥的管理。本版本不提供 S1，客户不能自己登录。
6. **真实客户资料只在 RF-DEC-07 签批后录入**，并且只存放在试运营 VPS 及其加密备份里。生产身份、真实地图与地理编码、KESS 与真实支付均未接入。
