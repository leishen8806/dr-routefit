## 目标

把官网首页改成“一屏一版”：电脑上滚一下停在下一屏，每屏讲配送链路上的一个环节，配一张等距 3D 风格画面和讲这个环节的动效。先做中文预览页给负责人看，满意后再做三语正式版。

## 画面

- 风格：**等距 3D**，干净的形体、柔和光影、品牌色（深蓝 #0B2545、青绿 #13C29B、琥珀 #F5A623），有设计感；画面里**不出现任何文字、招牌字、车身标志**。
- 第 1、2 屏已有 AI 生成图（负责人从 Canva 下载后放到 `E:\RouteFit-QA\ops\website-design\images\screen-1.png`、`screen-2.png`）；若文件不存在或风格与其余几屏差异太大，改用代码绘制。
- 第 3–6 屏用代码绘制等距 3D 场景（内联 SVG，可配合 CSS 3D 变换），风格与第 1、2 屏尽量一致；每屏另写一段可用于 AI 出图的提示词，放 PR 描述里，供以后替换。
- 所有图片压缩为 WebP，单张不超过 250 KB，非首屏延迟加载。

## 交互要求

1. 电脑（宽 ≥ 1024 且高 ≥ 700）：CSS `scroll-snap-type: y mandatory`，每屏 `min-height: 100svh`、`scroll-snap-align: start`；**不用脚本接管滚轮**；键盘上下键、PageDown、空格可切屏；右侧一列六个小圆点表示当前屏，可点击跳转，有可读的无障碍标签。
2. 手机和矮屏：不吸附，自然滚动；每屏内容完整显示，不截字。
3. 动效：进入视口时播放一次（IntersectionObserver），只用 `transform` 和 `opacity`；同一套缓动曲线和 2–3 个时长；不循环、不闪烁、不悬停放大。
4. `prefers-reduced-motion: reduce` 时全部动效关闭，直接显示最终状态，滚动吸附也关闭。
5. 性能：首屏 LCP 本机节流到“快速 3G”下 ≤ 2.5 秒；整页图片总量 ≤ 1.5 MB。
