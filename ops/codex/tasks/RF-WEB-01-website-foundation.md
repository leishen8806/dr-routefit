## 背景

RouteFit 需要一个对外官网，放在 `[官网域名]`，用独立的静态托管，不放在试运营服务器上。整体规划已由负责人确认：共 11 个页面，分 4 个批次。本卡是批次 1。

设计稿（四个页面：首页、司机与车队、价格说明、联系我们）由负责人提供，是本机文件，不在仓库里。这些文件是设计软件的格式，按里面的 HTML 结构和内联样式读取视觉规格即可，不把这些文件或其中的设计软件运行脚本提交进仓库。

## 要做

1. **站点框架：** 在仓库新增 `website/` 目录，用 Astro 生成纯静态站点（版本固定，在 PR 里写明）。不用后端，不用服务端渲染。
2. **三语路由：** `/km/`、`/en/`、`/zh/` 三套地址，每个页面三种语言一一对应。
   - 根路径 `/` 按浏览器语言跳转，判断不出来时跳到 `/km/`；访客手动选过的语言要记住（只存在浏览器本地，不用 Cookie 追踪）。
   - 顶栏的语言切换用原生名称 `ខ្មែរ / English / 中文`，不用国旗；切换后停在同一页。
   - 每页的 `<html lang>` 与当前语言一致，并输出三种语言互相标注的 `hreflang`。
3. **文案与翻译：** 所有文案放在按语言分开的内容文件里，不写死在组件中。
   - 中文以设计稿为准；
   - 英文按中文翻译；
   - 高棉语先放机器翻译初稿，文件开头标注“待母语审校，审校前不得上线”，并在 PR 里列出所有待审校的条目。
   - 品牌名 `DR RouteFit` 和 Slogan `The right vehicle. The right route. On time` 不翻译。
4. **公共部分：** 顶栏（Logo、导航、语言切换、“联系我们”按钮）、页脚（四栏导航、服务条款和隐私政策的链接、版权行），按设计稿实现。手机宽度下导航要能折叠或换行，不能出现横向滚动。
5. **首页：** 按设计稿实现全部区块：首屏、三个快速入口、“车对货 / 路对线 / 准时送到 / 每一步有记录”、四步下单流程、服务区域、司机招募与商务合作两张卡、常见问题。
   - “查询订单”入口显示为“即将开放”，不做真实查询；
   - 其他页面的链接先指向占位页，占位页写“即将上线”，属于批次 2 的范围。
6. **品牌：** 颜色、字体以设计标准和设计稿为准。青绿和橙色不能用作白底上的文字。高棉语要放大行高，避免上下标被裁切。Logo 用 `brand/logo/` 下现有的 SVG，不重新设计。
7. **占位信息：** 联系方式、公司主体名称、价格等未定信息保留方括号占位，不得编造。
8. **SEO 基础：** 每种语言各自的页面标题和描述；`sitemap.xml`；`robots.txt` 先设置为禁止收录（正式上线时再打开）；分享预览用的图片和标题。
9. **CI：** 新增 `website` 任务，运行构建、链接检查和一次无障碍自动检查。把 CI 项数从六项改为七项，并列出 `website`。
10. **部署配置（不部署）：** 在 `website/README.md` 写明静态托管的构建命令、输出目录、Node 版本，以及根域跳转到官网主机名的规则。不要创建或修改任何托管设置、DNS 记录，也不要部署。

## 不做

- 批次 2 及以后的页面和表单；
- 表单提交、查单、Telegram 下单入口、App 下载；
- 访问统计、Cookie、任何收集访客数据的功能；
- 修改业务系统代码、`services/`、`apps/`、`contracts/`；
- 部署、改 DNS、改托管设置。

## 验收

- CI 七项全绿；
- 三种语言的首页都能访问，语言切换后停在同一页，`lang` 和 `hreflang` 正确；
- 在 390 px 手机宽度和 1440 px 电脑宽度下截图对比设计稿，没有横向滚动，高棉语文字没有被裁切；
- 无障碍检查没有严重问题；交互元素可以用 Tab 键操作，点击区域不小于 44 px；
- 没有编造的数字、承诺或联系方式；
- PR 描述按“要做”逐项写 PASS／FAIL／NOT_RUN，并附高棉语待审校清单；范围外的发现写进“发现但未处理”。
