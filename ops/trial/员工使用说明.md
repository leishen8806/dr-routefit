# 受控试运营员工端使用说明

部署模板约定 SSH 组名为 `rf-tunnel`、服务路径为 `/srv/routefit`；登录辅助由 `/usr/local/lib/routefit/routefit-tunnel-link` 包装器启动，部署时由 RF-OPS-01 写入 Node 24 可执行文件绝对路径 `<NODE24_PATH>`。

1. 先把 `routefit-tunnel.bat` 的 `<SSH_PORT>`、`<EMPLOYEE_ACCOUNT>` 和 `<VPS_ADDRESS>` 替换为负责人发放的值；仓库模板不包含真实地址。
2. 双击 `.bat` 文件，保持弹出的 SSH 窗口打开。窗口关闭后，浏览器到 VPS 的本地隧道会立即断开。
3. SSH 登录后脚本会打印一次性浏览器链接；请在 60 秒内**从这个窗口复制链接，粘贴到浏览器的地址栏**打开。链接只使用一次，不要转发或记录。不要把链接存进本地网页或文档里再点击跳转：服务端会按设计拒绝跨站来源的跳转。
4. `.bat` 里的 `ssh -T` 不要删除。服务器按设计禁止分配终端（PTY），不加 `-T` 时隧道不能保持连接。自己另写 ssh 命令时同样要加 `-T`。
5. 本机 `4180` 被占用时，先关闭占用该端口的本地 RouteFit/开发服务；不要修改隧道目标端口。若无法释放端口，联系负责人安排其他本机端口并同步修改服务配置。

**各角色能做什么：**

| 角色 | 能做 | 不能做 |
| --- | --- | --- |
| 录单报价 | 录单、登记受理依据、提交受理、生成报价、记录客户确认、登记改址申请 | 决定改址申请；编制、复核、发布费率策略 |
| 案件决定 | 查看订单、报价和改址申请，对改址申请做出接受或拒绝的决定（必须填原因） | 创建或编辑订单、生成报价、登记改址申请 |
| 费率编制、费率复核、费率发布 | 各自负责的一步 | 另两步；同一个人不能兼任其中两个角色 |

登记改址申请的人和决定的人必须是不同的人，系统会拒绝同一个人既登记又决定。

**生成报价的临时规则（2026-11-03 起，负责人通知解除前有效）：**

- 目前服务器上唯一生效的费率策略是合成测试策略，不是正式费率。在负责人通知"正式费率已发布"之前，可以录单、登记受理依据、提交受理，**不要生成报价，也不要记录客户确认**。
- 正式费率发布后，生成报价前先看订单页策略下拉框里每一项的有效期。策略列表只显示此刻有效的策略；如果下拉框里有不止一项，或有效期与负责人通知的不一致，**不要生成**，先联系负责人。
- 改址申请的候选报价同样遵守以上规则。

员工 SSH 账号名必须等于员工登记里的 `sshLogin`。正式员工的密钥由员工本人在自己电脑上生成并设置口令，只交公钥。本说明只覆盖员工端操作；VPS 加固、账号、systemd 和 SSH 配置由 RF-OPS-01 负责。
