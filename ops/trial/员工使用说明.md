# 受控试运营员工端使用说明

部署模板约定 SSH 组名为 `rf-tunnel`、服务路径为 `/srv/routefit`；登录辅助由 `/usr/local/lib/routefit/routefit-tunnel-link` 包装器启动，部署时由 RF-OPS-01 写入 Node 24 可执行文件绝对路径 `<NODE24_PATH>`。

1. 先把 `routefit-tunnel.bat` 的 `<SSH_PORT>`、`<EMPLOYEE_ACCOUNT>` 和 `<VPS_ADDRESS>` 替换为负责人发放的值；仓库模板不包含真实地址。
2. 双击 `.bat` 文件，保持弹出的 SSH 窗口打开。窗口关闭后，浏览器到 VPS 的本地隧道会立即断开。
3. SSH 登录后脚本会打印一次性浏览器链接；请在 60 秒内复制到浏览器打开。链接只使用一次，不要转发或记录。
4. 本机 `4180` 被占用时，先关闭占用该端口的本地 RouteFit/开发服务；不要修改隧道目标端口。若无法释放端口，联系负责人安排其他本机端口并同步修改服务配置。

员工 SSH 账号名必须等于员工登记里的 `sshLogin`。正式员工的密钥由员工本人在自己电脑上生成并设置口令，只交公钥。本说明只覆盖员工端操作；VPS 加固、账号、systemd 和 SSH 配置由 RF-OPS-01 负责。
