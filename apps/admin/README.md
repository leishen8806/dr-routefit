# RouteFit Admin

## 选型说明

管理后台采用现有的 Expo Router 网页端运行时，并复用仓库中已锁定的 React、React Native Web、Expo Router 和字体包；本卡不新增或升级依赖。根工作区仅登记 `apps/admin`，由本卡维护。

页面壳由本卡维护：登录壳、桌面侧栏、12 个菜单、路由和公共布局。业务页面按目录边界由 Frontend1 与 Frontend2 维护；本卡只提供稳定的导航和页面插槽，不改其子目录。

所有数据均为标注“示例”的本地展示数据；不会请求支付、地图、短信或其他外部服务。真实权限、金额和操作校验仍由服务端负责，前端只呈现状态。

## 实施顺序

1. 用 Node 单测锁定 12 个菜单和本卡拥有的 4 条路由，再实现导航配置。
2. 建立 Expo Router 网页端入口、三语字体和高棉语行高规范。
3. 实现登录壳与共用后台布局，随后以模拟数据实现看板、调度、自动排线和配送区域页面。
4. 逐项执行单测、类型检查、网页构建和浏览器验收；页面合并前不触碰 Frontend1、Frontend2 的子目录。
