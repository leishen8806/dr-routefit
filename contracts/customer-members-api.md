# 客户门户成员接口（本机实现）

这四个接口用于企业客户门户的成员授权：读取成员、登记邀请、停用、撤销。它们在本机 API 中已实现，但尚未部署，也尚未连接生产身份提供方或邮件服务。

## 安全与状态边界

- 仅当前货主的 `portal:members:manage` 管理员可访问；第一次配置前，既有 `party.customer_access` 可完成一次管理权引导。
- 邀请只写入审计记录，状态为 `invited`；不会发邮件、不会创建账号，也不会自动授予数据访问。
- 管理员只能委派自己已有的门户权限；最后一名有效成员管理员不可被停用或撤销。
- 停用、撤销要求 `If-Match` 版本和变更原因；历史事件只追加。
- 身份提供方将邀请关联为有效自然人、通知投递以及生产权限同步，仍是未实现的部署前依赖。

接口字段与状态以 [endpoint-catalog.md](endpoint-catalog.md) 和 [fields.md](fields.md) 为准。
