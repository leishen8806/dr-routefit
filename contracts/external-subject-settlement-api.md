# 商户与合作方结算接口（本机实现）

商户端仅查看自身 COD 应付账项；合作方端仅查看自身承运费应付账项。两端均可查看已签发的本主体账单、已核验的脱敏结算账户，以及提交结算申请。

## 控制边界

- 主体由 `org.external_subject_access` 的有效会话映射决定；请求没有 `subjectId` 参数，因此不能借参数越权读取其他商户、承运商或客户原价。
- 商户只读取 `COD`、合作方只读取 `CARRIER` 的 `PAYABLE` 账项。申请会重新检查账项、币种、账户版本和已提交申请的预留额。
- 结算申请状态仅为 `submitted`，不代表复核、审批、银行执行、到账或入账完成；这些动作仍由内部财务流程处理。
- 账户变更和外部主体绑定不由此接口完成，需通过受控的 IdP／账户审核流程写入。

接口字段和实现状态以 [endpoint-catalog.md](endpoint-catalog.md) 为准。
