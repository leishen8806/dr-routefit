# 收货授权接口 · R1 本地开发切片

收货授权是运营核验后的独立事实，不是司机点击完成，也不是最终签收。它绑定订单当前版本、交付窗口和订单证据；地址、收货对象、执行计划或订单版本改变后，旧授权不会匹配新交付。

| 操作 | 路径 | 约束 |
|---|---|---|
| 核验并登记 | `POST /api/ops/v1/orders/{orderId}/recipient-authorizations` | 仅有效运营人员；订单必须在 `executing/in_transit`；授权证据必须归属订单；有效期不超过本次交付窗口。 |
| 读取当前授权 | `GET /api/driver/v1/orders/{orderId}/recipient-authorization` | 仅本单已接受且已持有全部件的当前司机；无当前有效授权统一返回 404。 |

司机没有创建或修改收货授权的接口。后续签收必须再核对本接口返回的授权 ID、件级交付证据、收款门槛和订单版本；本切片尚未实现最终签收、代理人身份核验渠道或收货人自助验证。
