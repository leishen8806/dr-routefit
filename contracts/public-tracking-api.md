# 公开订单跟踪 API · v0.1

`GET /api/public/v1/tracking/{ref}` 已在本机实现。`ref` 是 22–128 位 URL 安全字符的高熵能力引用；服务端只传递其 SHA-256 哈希到数据库函数查询，日志不记录引用值。

响应仅包含脱敏单号、履约状态、承诺窗口／ETA、更新时间、质量和获批准的平台联系入口。客户姓名、电话号码、地址、车辆轨迹、同车订单与财务信息均不在投影中。

引用不存在、撤销或过期均统一返回 `404`；接口限流并返回 `Cache-Control: no-store`。当前只实现读取；能力引用的签发、撤销工作流和客户通知仍需由后续内部受控能力补齐，不能手工把订单 ID 当成公开链接。
