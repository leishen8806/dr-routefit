# 财务导出接口（本机实现）

`POST /api/ops/v1/finance/exports` 生成受控 CSV，`GET /api/ops/v1/finance/exports/{exportId}` 取得当前导出状态与短期下载链接。

- 导出按创建人、企业、当前 `finance:export` 权限和可选主体范围限制；下载时再次验证会话和创建人，不把链接作为长期授权。
- 支持账项、账龄、账单、现金交接、COD 与仓储请求导出；导出的是业务明细，不是会计凭证。
- CSV 单元格统一引用，对以 `=`, `+`, `-`, `@` 开头的值增加文本前缀，避免电子表格公式注入。
- 结果五分钟后过期；本机实现将 CSV 保存在数据库导出任务内，不接对象存储或生产归档策略。
